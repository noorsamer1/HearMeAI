Place your realistic signer model here:

- Required file name: `signer.glb`
- Path: `frontend/public/models/signer.glb`

Recommended model requirements:

- Rigged humanoid body with clear hand bones/fingers
- Includes animation clips named with friendly keywords:
  - `idle` / `neutral`
  - `wave` / `hello`
  - `thank`
  - `yes`
  - `no`
  - `please`
  - `help`
  - `question` / `how`

The app auto-detects this file and uses it in the hologram panel.
If missing, it falls back to the built-in procedural hologram robot.
